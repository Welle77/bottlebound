# Release notes - Ability activation and effect expiry

Change: Added
Maturity: Beta
Audience: users
Action required: No
Finalized: 2026-08-23

## Summary

Automated the 24-ability roster through Action Draft: targeted attacks reuse the guided flow, physical attacks run ordered AttackLegs with per-hit damage and prohibition, utility abilities apply heal, revive, maxHP, movement caps and ignore, and every temporary effect expires atomically on scheduled-slot or turn boundaries or Downed cleanup.

## User and operator impact

Referees can now select any Standard or Powerful ability from the active character, see ability-already-spent behind override, and have effects and expiries recorded in the same Match Event so Undo reverses the whole activation. Matches persist offline and restore exactly after restart.
