# Manual release checklist

Run these checks on the target Android phone or tablet with current stable Chrome. Browser simulation does not complete the physical checks.

- [ ] Install the Referee Console while online. Close Chrome, disable network access, open the installed console, and check exact Setup and Active Match restore.
- [ ] Use the console in direct sunlight. Check that all status text, initiative rows, active state, and confirmations stay readable.
- [ ] Hold the device in one hand. Create a Match, generate initiative, start it, finish turns, and confirm Undo without unsafe grip changes.
- [ ] Use a safely damp fingertip. Check that each main control accepts one deliberate press without missed or adjacent activation.
- [ ] Run the console for a representative full Match duration. Check device heat, battery behavior, screen responsiveness, and stored-state restore afterward.
